# 🎙️ Gappey - Voice Party Chat Room App Landing Page

A luxurious, high-performance **Next.js** landing page for **Gappey** — the premier voice party social entertainment platform featuring 16 dynamic live seats, SVGA animated broadcast gifts, dual-level whale & stardom progression, VIP prestige clubs, and social gaming.

Built for seamless one-click deployment on **Vercel** with full responsiveness, interactive animated gifts simulator, live video recording player, 3D blended device mockups, in-app screen showcase with fullscreen zoom, Google Play pre-registration, and direct Android APK downloads.

---

## ✨ Features

- 📱 **Seamless 3D App Mockup Blend**: Custom dark purple / gold neon glow aesthetic matching Gappey's brand identity.
- 🎥 **Live Screen Recording Player**: In-phone video player featuring the actual screen recording with custom play, pause, volume, and seek controls.
- 🎙️ **16-Seat Live Audio Stage**: Detailed feature showcase of low-latency voice, speaker wave rings, and host controls.
- 💎 **Dual-Level Progression**: Visual breakdowns of *Blue Level* (Whale Gifting Power) & *Pink Level* (Host Popularity & Stardom).
- 🎁 **Interactive Gift Simulator**: Interactive tap-to-send simulator with animated gifts (`rose.gif`, `ship.gif`, `kiss.gif`, `laugh.gif`, `aurum dragon`, `rocket`, `taj mahal`) and real-time confetti combos.
- 🖼️ **In-App Screenshots Gallery**: Interactive category filtering and fullscreen zoom viewer for all core screens (Voice Rooms, Gift Drawer, VIP Prestige, Leaderboards, Daily Rewards, and Agency Dashboards).
- 🚀 **Google Play Pre-Registration**: Interactive registration form with instant celebration confetti and Early Bird Founding Badge confirmation.
- 📥 **Direct APK Download**: Fast direct Android APK download powered by Expo EAS CDN.
- 💼 **Digital Product Services Banner**: Subtle, elegant section connecting clients with Instagram `@khushi_jha16` for custom mobile apps, web applications, backends, DevOps, and desktop software.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+ (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Custom Neon Glassmorphism
- **Animations & FX**: `canvas-confetti`, `lucide-react` icons, smooth CSS keyframes
- **Deployment**: [Vercel](https://vercel.com) ready out of the box

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 📦 APK Download Configuration (`src/constants/links.ts`)

Direct APK downloads point to the EAS cloud build artifact:
- Update `APK_DOWNLOAD_URL` in `src/constants/links.ts` whenever a new EAS preview/production build is generated.

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub: `https://github.com/pritammajumder16/Gappey-Landing`
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import the `Gappey-Landing` repository.
4. Click **Deploy**. Vercel will automatically build and assign a global CDN URL!
